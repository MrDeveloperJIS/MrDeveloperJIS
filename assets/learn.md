## HTML & CSS

> The foundation of every web page: HTML gives it structure, CSS gives it style and layout.

| Resource | Type | Level | Why it's useful |
|---|---|---|---|
| [MDN Web Docs](https://developer.mozilla.org/en-US/docs/Web) | 📖 | 🟢–🔴 | The official, most trusted reference for HTML, CSS and Web APIs. |
| [MDN Learn Web Development](https://developer.mozilla.org/en-US/docs/Learn_web_development) | 🎓 | 🟢 | A structured beginner curriculum from the same team. |
| [web.dev Learn](https://web.dev/learn) | 🎓 | 🟢–🟡 | Modern, well-written courses on HTML, CSS, accessibility and responsive design. |
| [freeCodeCamp](https://www.freecodecamp.org/) | 🕹️ | 🟢 | Interactive exercises with certifications and projects. |
| [W3Schools](https://www.w3schools.com/) | 📖 | 🟢 | Quick examples with a "Try it yourself" editor. |
| [The Odin Project](https://www.theodinproject.com/) | 🎓 | 🟢–🟡 | Free full-stack path with real projects. |
| [Flexbox Froggy](https://flexboxfroggy.com/) / [Grid Garden](https://cssgridgarden.com/) | 🕹️ | 🟢 | Learn Flexbox and Grid by playing a game. |
| [CSS-Tricks: Flexbox](https://css-tricks.com/snippets/css/a-guide-to-flexbox/) / [Grid](https://css-tricks.com/snippets/css/complete-guide-grid/) | 📖 | 🟡 | The classic visual cheat sheets you'll keep coming back to. |
| [Can I use](https://caniuse.com/) | 🛠️ | 🟡 | Check browser support before using a new feature. |

**Practice:** rebuild a landing page you like · [Frontend Mentor](https://www.frontendmentor.io/) challenges · make your portfolio responsive.<br>
**Good habits:** use semantic tags (`<header>`, `<main>`, `<nav>`), write mobile-first CSS, and add `alt` text to every image.

## Suggested Learning Order

```text
 HTML → CSS → Git & GitHub → JavaScript → Bootstrap
                    │              │
                    ▼              ▼
          Linux & Markdown      jQuery (as needed)
                    │
                    ▼
        SQL → C / Python / Java → WordPress (CMS projects)
```

1. **Weeks 1–4:** HTML, CSS, Git basics. Publish a page on GitHub Pages.
2. **Weeks 5–10:** JavaScript + Bootstrap. Build 3 small projects.
3. **Weeks 11–14:** Linux basics + SQL. Build something that stores data.
4. **Ongoing:** C (to understand fundamentals), plus Python or Java. Contribute to open source.

---

## 💡 How to Learn Effectively

- **Build, don't just watch.** For every hour of tutorial, spend two hours building.
- **Read the docs.** MDN and official documentation beat most videos in the long run.
- **Commit daily.** Small, regular commits build a skill (and a contribution graph).
- **Explain it.** Write a short blog post or README about what you learned.
- **Ask well.** Search first, then post a minimal example on [Stack Overflow](https://stackoverflow.com/) or [dev.to](https://dev.to/).
