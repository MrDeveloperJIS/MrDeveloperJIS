# Learning Resources

## HTML & CSS
- [MDN Web Docs](https://developer.mozilla.org/en-US/docs/Web) – Comprehensive, official reference and tutorials.
- [W3Schools](https://www.w3schools.com/) – Beginner-friendly tutorials and examples.
- [FreeCodeCamp](https://www.freecodecamp.org/) – Interactive coding exercises.

## Bootstrap
- [Official Bootstrap Docs](https://getbootstrap.com/docs/) – Best for reference and examples.
- [W3Schools Bootstrap](https://www.w3schools.com/bootstrap4/) – Beginner-friendly tutorials.

## Markdown
- [Markdown Guide](https://www.markdownguide.org/) – Complete guide with examples.

## JavaScript
- [MDN JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript) – In-depth documentation and tutorials.
- [Eloquent JavaScript](https://eloquentjavascript.net/) – Free book for deeper understanding.
- [JavaScript.info](https://javascript.info/) – Structured tutorials from basics to advanced.

## SQL
- [W3Schools SQL](https://www.w3schools.com/sql/) – Easy to follow and interactive examples.
- [SQLBolt](https://sqlbolt.com/) – Interactive lessons and exercises.
- [Mode SQL Tutorial](https://mode.com/sql-tutorial/) – Practical SQL queries.

## C Programming
- [Learn-C.org](https://www.learn-c.org/) – Free interactive C tutorials.
- [GeeksforGeeks C Programming](https://www.geeksforgeeks.org/c-programming-language/) – Detailed explanations and examples.

## Git & GitHub
- [Git Official Docs](https://git-scm.com/doc) – Authoritative Git reference.
- [GitHub Learning Lab](https://lab.github.com/) – Interactive GitHub tutorials.
- [Atlassian Git Tutorial](https://www.atlassian.com/git/tutorials) – Beginner-friendly and visual guides.

## Linux
- [Linux Journey](https://linuxjourney.com/) – Beginner to advanced topics.
- [TutorialsPoint Linux](https://www.tutorialspoint.com/unix/index.htm) – Step-by-step tutorials.
- [LinuxCommand.org](http://linuxcommand.org/) – Focused on command-line mastery.

## WordPress
- [WordPress.org Codex](https://wordpress.org/support/article/wordpress-lessons/) – Official tutorials and guides.
- [WPBeginner](https://www.wpbeginner.com/) – Practical tutorials for beginners.
- [Learn WordPress](https://learn.wordpress.org/) – Free courses by WordPress.
